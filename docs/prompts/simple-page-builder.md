# Prompt: Simple Page Builder

Implement a designated Simple/free Government Watchdog route as a warm, readable broadsheet surface. Use `docs/product/*` as binding requirements and the matching `*.dc.html` only as visual guidance.

## Must include

- official ID/context, source receipts, trust/gap/pending labels, and a supported next action
- all route states in `route-and-state-matrix.md`
- one-column mobile reading order and accessible source/action controls
- links that work or are absent; unavailable features state why

## Must not

- hide evidence to upsell Advanced
- copy fictional Design Canvas claims into data
- expose reviewer/internal fields or paths
- create billing, authentication, notification persistence, or fake search/alerts

Return: exact changed files, state coverage, tests, visual viewport evidence, and any blocked contract fields.
